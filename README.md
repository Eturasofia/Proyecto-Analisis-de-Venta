Analisis de ventas.

Integrantes:
-Hugo: Lider y organizador
-Paco: Desarrollador tecnico.
-Luis: Revisor y Qa

Descipcion: El proyecto consiste en el desarrollo de una herramienta que permita anailzar ventas de una pequeña empresa.
Ojetivo: Automatizar el procesamiento de datos para evaluar el rendimiento del negocio, identificar tendencias y facilitar la toma de decisiones. 

Dataset:
-Producto: nombre o identificacion del articulo
-Cantidad vendad: Unidades del producto que fueron despachadas en cada transaccion 
-Precio: Valor unitario del producto.
-Fecha de venta: Registro temporal en el que se efectuo la operacion. 

Instrucciones para el scripts:
1. Asegurarse de contar con Python 3 instalado.
2. Colocar el archivo de datos en 'datos/ventas.csv'.
3. Ejecutar el script principal desde la terminal:
   python scripts/analisis.py
4. Los reportes resultantes se generarán automáticamente en la carpeta 'resultados/'.
